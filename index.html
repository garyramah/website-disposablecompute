A LIVING KNOWLEDGE BASE · VENDOR SCORECARD

Disposable compute is the execution substrate of the agent economy.

Agents that write and run code, browse the web, or operate tools need isolated sandboxes they can trust to be thrown away — a fresh microVM or container per task, so a mistake or a malicious prompt can't damage anything persistent. This site tracks, in one standardized evaluation matrix, which commercial providers actually deliver that primitive, and at what price.

01Thesis

Why this category exists, and the one claim nobody in it can currently prove.

Two demand drivers compound. First, trust: every agent that touches the world does it through a sandbox, and the economic value isn't the compute — it's the disposal guarantee. Second, economics: agent code-execution is bursty by nature (thousands of short-lived environments), and GPU capacity is the most expensive thing to leave idle. Rent capacity for exactly as long as the job needs; destroy the rest.

The market is pricing it in now: sandbox vendors raised at infrastructure valuations through 2026, and every hyperscaler ships a disposable primitive — Lambda, Cloud Run, Spot VMs, Workers, Machines.

The disposal-attestation gap. The disposal guarantee is only as good as its enforcement — and today it is vendor-claimed, not verified. Nobody attests that the sandbox actually destroyed the state. "This VM was thrown away" is an unverified assumption about the state of the system. The vendor that closes this gap — attested teardown, invocation-bound proof that nothing persisted — owns the trust layer, not just the compute layer.

02The Evaluation Matrix

Five categories. Every vendor in the scorecard is tracked against this schema. Benchmarks are the industry's observed thresholds, not marketing claims.

Provisioning & Elasticity

Boot time: <10ms for Wasm/Isolates · <150ms for Firecracker microVMs · >10s for standard VMs
Concurrency: maximum concurrent sandboxes per account/tier
Scale-to-zero: supported, and what "zero" bills (disk only vs. nothing)

Pricing Model

Billing granularity: per-millisecond vs. per-second — and what the meter counts (wall-clock vs. active CPU is the real divide)
CPU/memory bundling: independent scaling vs. fixed ratios
GPU availability: self-serve vs. enterprise-gated; per-second H100/B200 billing
Network egress markups

Workload Fit

Max execution duration: 15 min AWS Lambda (standard) · 90 min Lambda Managed Instances (async) · 24h Cloud Run Jobs · no cap GCP Spot VMs
Stateful volume attachment: speed and cost of persistent disks
GPU passthrough inside the sandbox trust boundary

Isolation Architecture

Underlying primitive: Shared Kernel/Docker · gVisor · Firecracker/KVM · Kata Containers · V8 Isolates
Ranked by boundary strength for untrusted code: microVM > gVisor > containers > isolates (isolates win on speed, lose on kernel sharing)

Governance & Guardrails

Network egress locking: deterministic, default-deny outbound
Ephemeral identity injection: OIDC / SPIFFE / short-lived IAM
TTL hard-kill switches: automated, non-bypassable teardown
Disposal attestation: no vendor currently offers this — the gap

AWS Lambda

FIRECRACKER MICROVM · THE REFERENCE
Elasticity
1,000 concurrent/account default; 1,000 new environments per 10s per function. Scales to zero.
Pricing
$0.20/M requests + GB-seconds, per-ms. CPU locked to memory ratio — the classic bundling constraint.
Workload fit
15 min standard; 90 min on Lambda Managed Instances (async/event-source, since Sep 2026). No GPU.
Isolation
Firecracker/KVM — the primitive the whole category copied.
Governance
IAM roles = ephemeral identity; VPC + resource policies for egress; timeout = TTL kill.
Verdict: the incumbent reference. Managed Instances quietly retired the "15-minute" objection for async workloads.

GCP Spot VMs

FULL KVM VM · THE BURSTY-GPU PLAY
Elasticity
Quota-bound; minutes to boot. No scale-to-zero — you manage the lifecycle.
Pricing
Per-second (1-min minimum), up to 91% off on-demand. H100 ≈ $3.30/hr on spot.
Workload fit
No runtime cap on Spot (legacy preemptible was 24h). 30-second preemption notice — checkpoint or die.
Isolation
Full KVM VM — strongest boundary, slowest boot.
Governance
Service accounts / OIDC; preemption is a hard kill but an unverifiable one.
Verdict: cheapest bursty GPU on paper; the preemption model is disposal-by-force, not disposal-by-guarantee.

Fly.io Machines

FIRECRACKER MICROVM · THE PRAGMATIST
Elasticity
~300–600ms wake; per-second billing; stopped machines bill disk only ($0.15/GB-mo).
Pricing
shared-cpu-1x/256MB ≈ $2.19/mo always-on. Egress $0.02/GB NA/EU, $0.12 Africa/India.
Workload fit
Runs until stopped. Fly Volumes for state. On-demand NVIDIA GPUs.
Isolation
Firecracker/KVM on bare metal.
Governance
Machine stop API as TTL; private WireGuard networking.
Verdict: the cheapest honest microVM meter; you own the lifecycle, which is the price of the price.

E2B

FIRECRACKER MICROVM · THE AGENT-NATIVE DEFAULT
Elasticity
~150ms claimed boot; 20 concurrent Hobby, 100–1,100 Pro. Scales to zero.
Pricing
$0.0504/vCPU-hr + $0.0162/GiB-hr, per-second wall-clock — the meter runs while your agent waits on the model.
Workload fit
1h Hobby / 24h Pro sessions. No self-serve GPU (enterprise only).
Isolation
Firecracker/KVM, open runtime (Apache-2.0) — self-hostable.
Governance
Session timeout = hard kill; isolated network default.
Verdict: deepest isolation of the specialists; wall-clock billing punishes idle-heavy agent loops.

Modal

GVISOR · THE GPU CATALOGUE
Elasticity
Sub-second claimed cold starts; aggressive idle reclaim; scales to zero.
Pricing
$0.1419/core-hr sandbox (~3× base compute) + $0.024/GiB-hr, per-second. Egress $0.04/GB since Oct 1, 2026.
Workload fit
5 min default → 24h max. Full self-serve GPU: T4 → B200 ($3.95–$6.25/hr H100/B200).
Isolation
gVisor user-space kernel (VM in beta) — middle ground for agent-generated code you partially trust.
Governance
Timeout reclaim; SOC 2 + HIPAA published.
Verdict: the GPU shortlist is Modal or Daytona — Modal wins catalogue depth, loses on unit price.

Cloudflare Workers

V8 ISOLATES · THE SPEED EXTREME
Elasticity
<5ms cold start; effectively unlimited concurrency; scales to zero.
Pricing
$5/mo + $0.30/M req; CPU-time billing — idle I/O wait is free. 128MB fixed memory, money can't fix it.
Workload fit
30s default / 5 min max CPU; Cron/Queue 15 min. No in-sandbox GPU.
Isolation
V8 isolates — fastest boot, shared process; wrong primitive for untrusted native code.
Governance
CPU-time cap as TTL; Cloudflare Sandbox (containers via Durable Objects) for heavier work at $0.072/active vCPU-hr.
Verdict: unbeatable for I/O-bound edge logic; not a sandbox for running untrusted binaries.

Daytona

CONTAINER (VM OPTIONAL) · THE UNICORN
Elasticity
Sub-90ms claimed creation; persistent sessions; 15-min idle auto-stop default.
Pricing
$0.0504/vCPU-hr + $0.0162/GiB-hr — identical to E2B, no subscription floor. H100 ~$2.27/hr live (ignore the stale $3.95).
Workload fit
Stateful sessions, pause/resume, GPU passthrough (up to 8 GPUs).
Isolation
Docker/Kata/Sysbox containers — weakest boundary of the set; VM sandboxes optional.
Governance
SOC 2/HIPAA/GDPR. Core went closed-source June 2026 — the auditability story changed.
Verdict: $1B valuation (Oct 20, 2026) on "a computer for every agent." Fastest creation, thinnest isolation — pick your tradeoff with eyes open.

Vercel Sandbox

FIRECRACKER MICROVM · THE IDLE-HEAVY WINNER
Elasticity
0.67s median in a 100-burst test (all succeeded); 10 Hobby / 10,000 Pro concurrent.
Pricing
$0.128/active vCPU-hr + $0.0212/GB-hr, per-ms, active CPU only — I/O wait is free.
Workload fit
45 min Hobby / 5h Pro. No GPU. Snapshots $0.08/GB-mo.
Isolation
Firecracker microVM, isolated network by default.
Governance
OIDC wired into the Vercel project; session timeout as TTL.
Verdict: for idle-heavy agent loops (71–98% of runtime waiting, per Vercel's own data), active-CPU billing beats wall-clock rivals 2.6–19×.

04Pricing Snapshot

Verified October 22, 2026. Pricing moves — this is a snapshot, not a quote. The structural finding matters more than any number:

The wall-clock vs. active-CPU divide

E2B, Modal, and Daytona bill wall-clock: the meter runs while your agent waits on a model response — which, for chat-style coding agents, is most of the runtime. Vercel Sandbox, Cloudflare, and AWS's agent primitives bill active CPU: idle I/O wait is free.

For idle-heavy workloads, the billing model matters more than the vendor. Same tasks, same isolation outcome — up to an order of magnitude apart on the invoice. Match the meter to the workload shape before comparing headline rates.
